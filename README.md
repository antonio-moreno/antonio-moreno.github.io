Laboratorio doméstico basado en OpenMediaVault y Docker Compose. Incluye servicios de gestión fotográfica con Immich y PhotoPrism, almacenamiento SSD/HDD, acceso remoto con Tailscale y pruebas de DNS y filtrado con AdGuard Home.

Uso de Raspberry Pi como plataforma ligera para experimentar con servicios de infraestructura, conectividad Ethernet, acceso remoto y filtrado DNS mediante herramientas como Tailscale y AdGuard Home.
