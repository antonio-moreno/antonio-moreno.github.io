# Actualizar el portfolio en GitHub Pages

1. Descomprime `Antonio_Rivero_Portfolio_Espacial.zip`.
2. En el repositorio `antonio-moreno/antonio-moreno.github.io`, abre **Add file → Upload files**.
3. Arrastra `index.html`, `styles.css` y `README.md` desde la carpeta descomprimida.
4. Confirma el commit en la rama `main`.
5. GitHub Pages publicará los cambios automáticamente.

Los tres archivos deben quedar directamente en la raíz del repositorio.
